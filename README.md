# AMBA RTL Design

## Introduction

This repository contains a collection of **RTL design projects based on the AMBA (Advanced Microcontroller Bus Architecture) specification**.

The projects focus on understanding and implementing commonly used AMBA protocols, including **APB, AHB, and AXI**, with an emphasis on **bus transactions, memory-mapped interfaces, address decoding, bridges, interconnects, and RTL verification**.

All designs are developed using **Verilog/SystemVerilog** and verified through simulation using tools such as **ModelSim, Questa, and Verilator**.

The main purpose of this repository is to build practical experience in **RTL Design, AMBA protocols, SoC interconnects, and digital system architecture**.
